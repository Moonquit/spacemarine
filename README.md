# Space ship in Solar System 

Курсовой проект по дисциплине **Компьютерная графика**.

Проект представляет собой интерактивную 3D-сцену полёта космического корабля в Солнечной системе. Приложение разработано на C++ с использованием OpenGL.

## Описание проекта

В сцене реализованы:
- управляемый космический корабль;
- вид от третьего лица;
- Солнце и планеты Солнечной системы;
- Земля, Луна, Марс, Юпитер и Сатурн;
- текстуры планет и звёздного неба;
- орбиты планет;
- астероиды в космическом пространстве;
- столкновения корабля с астероидами и планетами;
- эффект взрыва и автоматический респавн корабля;
- анимация вращения планет и астероидов;
- свет от Солнца;
- текстовый интерфейс с подсказками.

## Управление

| Клавиша | Действие |
|--------|----------|
| W / S | Движение вперёд / назад |
| A / D | Поворот влево / вправо |
| Q / E | Подъём / снижение корабля |
